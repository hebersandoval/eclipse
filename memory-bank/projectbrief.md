# Project Brief

## Project Name
**eclipse** (repository name) / **Simply Engineered** (business name)

## Project Type
Static website for a personal consulting/freelance services business, built with Eleventy.

## What This Project Is
A professional website for a freelance consultant/consulting services that will showcase:
- Services offered
- Value proposition and expertise
- Client testimonials
- Blog for thought leadership and content marketing
- Contact/lead generation

## Core Features
- Responsive landing page with hero section, services, packages, and testimonials
- Blog section with markdown-based posts
- Component-based architecture using Nunjucks templates
- Mobile-friendly navigation with collapsible menu
- CSS-based animations via AOS library

## Target Deployment
- Domain: www.simplyenginee.red
- Output: `_site/` directory (GitHub Pages compatible, uses `.nojekyll` file)

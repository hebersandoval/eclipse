Project Goal

Elevate the existing Simply Engineered website.

Do not redesign it.

Maintain the current brand identity while making the site feel comparable to premium software consulting companies.

Prioritize:

- readability
- whitespace
- typography
- accessibility
- maintainability
- performance

Technology

- Eleventy
- HTML
- Vanilla JS
- Modern CSS
- CUBE CSS
- BEM for reusable blocks

Never introduce frontend frameworks.

Never replace working code unless there is measurable improvement.

Every change should increase user trust and professionalism.

Prefer incremental pull-request-sized improvements.

Always explain tradeoffs before large refactors.

When unsure, choose the simpler solution.
